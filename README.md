# cloud-utils

Scripts for VPS setup, Docker, macOS helpers (Homebrew, DB sync, skills, git), MTProto, and Rclone.

## Quick start

```bash
git clone https://github.com/nguyenthanhan/cloud-utils.git ~/Documents/cloud-utils
```

Add to `~/.zshrc`:

```zsh
source "$HOME/Documents/cloud-utils/mac_init/load.zsh"
```
